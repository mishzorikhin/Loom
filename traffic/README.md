# Транспортный полигон

Второй проект в репозитории, с Loom не связан. Симулятор городской транспортной сети: улицы, перекрёстки со светофорами, машины, пешеходы, ДТП и опасные сближения. На нём нейросеть будет учиться управлять светофорами; человек видит всё на странице в 3D и может вмешаться.

Статус: работают движок, компилятор сети, сервер, страница, среда обучения, эталонные контроллеры и тесты. Самой нейросети ещё нет — среда для неё готова (`tsim/env.py`), как её подключить — `docs/training.md`.

Для графового трансформера среда отдаёт направленный граф с характеристиками дорог и снимок всей сети (`graph_observation()`): состояния перекрёстков, признаки рёбер, маски внимания и допустимых действий. Это позволяет модели учитывать связанные светофоры; обучение и сама модель пока не реализованы.

## Запуск

```
cd traffic
pip install -r requirements.txt
cd web && npm install && npm run build && cd ..
python3 -m tsim.server --port 8500            # страница: http://localhost:8500
python3 -m tsim.server --world grid           # или cross, corridor, district, grid2, или путь к JSON
```

Разработка страницы: сервер как выше, затем `cd web && npm run dev` (http://localhost:5180, сокет проксируется на 8500).

Прогон без картинки и сравнение контроллеров:

```
python3 -m tsim.run --world grid --controllers fixed,max_pressure --minutes 30 --seeds 3
python3 -m tsim.run --world cross --timing 0 --demand 1.4     # вариант B: без переходных стадий
python3 -m tsim.rollout --world grid2 --policy random,hold,max_pressure   # политики через среду обучения
```

Тесты: `cd traffic && python3 -m unittest discover -s tests`. Типы страницы: `cd web && npm run typecheck`.

## Что на странице

Экран разбит на верхнюю полосу, две колонки по краям и центр для сцены; блоки не накладываются, каждая колонка прокручивается сама. Центр кадра — середина свободной области между колонками.

- Сверху: мир (список: перекрёсток `examples/cross.json`, магистраль с Т-перекрёстками и переходом по вызову, решётки 3 × 3 и 2 × 2, вымышленный район с диагональным проспектом, район Перми из OpenStreetMap), часы симуляции, пауза (пробел), темп ×0,5…×40 и фактический темп (на больших мирах Python может не успевать), кнопки колонок, связь с сервером.
- Левая колонка, вкладка «Управление»: контроллер (фиксированный цикл, max-pressure, вручную, внешний агент), поток машин, пешеходы, **запас переходных стадий** (жёлтый, весь красный и мигающий зелёный в долях от безопасных; ниже 100% начинаются ДТП по вине светофора), запрет въезда на занятый перекрёсток, зерно и сброс.
- Левая колонка, вкладка «Осмотр»: открывается щелчком по объекту. Перекрёсток — стадия, фазы с состоянием групп, кнопки «включить» (переводит в ручной режим) с длительностями переходов, очереди на подходах. Машина или пешеход — карточка и слежение камеры; у машины видно, почему она так едет (красный, держит дистанцию, уступает пешеходу, выезд занят…). Esc закрывает.
- Правая колонка: сводка (машины в сети, доехавшие, средняя задержка, пешеходы, ДТП, сближения, график по минутам, причины ДТП, нарушения) и лента событий; щелчок по событию переносит камеру.
- Внизу центра: виды (1 — обзор, 2 — сверху, 3 — низко), слои (S — сигналы на полосах, C — точки конфликтов, H — тепловая карта, M — миниатюра), свет суток для картинки.
- Колонки: `[` и `]` сворачивают левую и правую (запоминается в браузере), P — обе. На узком экране (до 860 px) колонки — выдвижные шторки по кнопкам сверху.

## Файлы

- `docs/design.md` — устройство движка, модели поведения, ДТП, контроллеры, среда, что сделано и что замысел
- `docs/training.md` — обучение: наблюдение, действие, награда, метрики, маска, скорость, чего пока нет
- `docs/world-format.md` — формат описания мира и правила компилятора
- `docs/graphics.md` — страница и графика: технологии, слои сцены, стиль, проверка скриншотами
- `schema/world.schema.json` — схема описания мира (JSON Schema 2020-12)
- `examples/perm_mira.json` — район Перми (ул. Мира, шоссе Космонавтов), собран из OpenStreetMap командой `python3 -m tsim.osm` (см. ниже)
- `examples/cross.json` — перекрёсток магистрали и улицы с карманом и переходом по вызову
- `tsim/` — движок: `geom.py`, `compiler.py`, `generators.py` (решётка, магистраль, район; `from_graph` собирает мир из узлов и дорог под любыми углами, стрелки выводит по углам лучей), `scenery.py`, `signals.py`, `sim.py`, `env.py`, `run.py`, `worlds.py`, `osm.py`, `rollout.py`, `server.py`
- `web/` — страница (Vite + TypeScript + Three.js), собирается в `web/dist` (в git не входит)
- `tests/` — компилятор, ядро, светофор, среда и сервер

## Район из OpenStreetMap

`tsim/osm.py` превращает данные OpenStreetMap в описание мира: крупные дороги (primary, secondary, tertiary и съезды) обрезаются по окну, близкие перекрёстки склеиваются, две односторонние проезжие части сливаются в одну дорогу с разделительной полосой, полосы и стрелки выводятся по углам лучей. Мелкие улицы и дворы отброшены, а каждый перекрёсток получает светофор: нерегулируемых перекрёстков в формате версии 1 нет.

```
python3 -m tsim.osm fetch --bbox 57.9655,56.1480,57.9760,56.1700 --out raw.json
python3 -m tsim.osm convert raw.json --center 57.9707,56.1601 --window=-620,-400,620,520 --name "Пермь, ул. Мира" --out examples/perm_mira.json
```

Готовый результат — `examples/perm_mira.json` (мир `perm` на странице). Здания, парковки и зелень на странице рисует `scenery.py` по дорогам, а не по карте.

Данные © участники OpenStreetMap, лицензия ODbL (https://www.openstreetmap.org/copyright). Файл `examples/perm_mira.json` — производная база и распространяется на тех же условиях.
