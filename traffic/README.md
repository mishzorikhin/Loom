# Транспортный полигон

Второй проект в репозитории, с Loom не связан. Симулятор городской транспортной сети: улицы, перекрёстки со светофорами, машины, пешеходы, ДТП и опасные сближения. На нём нейросеть будет учиться управлять светофорами; человек видит всё на странице в 3D и может вмешаться.

Статус: работают движок, компилятор сети, сервер, страница, среда обучения, эталонные контроллеры и тесты. Самой нейросети ещё нет — среда для неё готова (`tsim/env.py`).

## Запуск

```
cd traffic
pip install -r requirements.txt
cd web && npm install && npm run build && cd ..
python3 -m tsim.server --port 8500            # страница: http://localhost:8500
python3 -m tsim.server --world grid           # или cross, corridor, grid2, или путь к JSON
```

Разработка страницы: сервер как выше, затем `cd web && npm run dev` (http://localhost:5180, сокет проксируется на 8500).

Прогон без картинки и сравнение контроллеров:

```
python3 -m tsim.run --world grid --controllers fixed,max_pressure --minutes 30 --seeds 3
python3 -m tsim.run --world cross --timing 0 --demand 1.4     # вариант B: без переходных стадий
```

Тесты: `cd traffic && python3 -m unittest discover -s tests`. Типы страницы: `cd web && npm run typecheck`.

## Что на странице

- Миры сверху: перекрёсток (`examples/cross.json`), магистраль с Т-перекрёстками и переходом по вызову, решётки 3 × 3 и 2 × 2.
- Часы симуляции и темп ×0,5…×40 (рядом фактический темп: на больших мирах Python может не успевать). Пробел — пауза.
- Слева управление: контроллер (фиксированный цикл, max-pressure, вручную, внешний агент), поток машин, пешеходы, **запас переходных стадий** (жёлтый, весь красный и мигающий зелёный в долях от безопасных; ниже 100% начинаются ДТП по вине светофора), запрет въезда на занятый перекрёсток, зерно и сброс.
- Справа сводка: машины в сети, доехавшие, средняя задержка, пешеходы, ДТП, сближения, график по минутам, причины ДТП, нарушения. Ниже лента событий, щелчок по событию переносит камеру.
- Щелчок по перекрёстку открывает его карточку: стадия, фазы с состоянием групп, кнопки «включить» (переводит в ручной режим) с длительностями переходов, очереди на подходах. Щелчок по машине или пешеходу — карточка и слежение камеры; у машины видно, почему она так едет (красный, держит дистанцию, уступает пешеходу, выезд занят…).
- Внизу виды (1 — обзор, 2 — сверху, 3 — низко), слои (S — сигналы на полосах, C — точки конфликтов, H — тепловая карта, M — миниатюра), время суток для картинки. P — скрыть панели.

## Файлы

- `docs/design.md` — устройство движка, модели поведения, ДТП, контроллеры, среда, что сделано и что замысел
- `docs/world-format.md` — формат описания мира и правила компилятора
- `docs/graphics.md` — страница и графика: технологии, слои сцены, стиль, проверка скриншотами
- `schema/world.schema.json` — схема описания мира (JSON Schema 2020-12)
- `examples/cross.json` — перекрёсток магистрали и улицы с карманом и переходом по вызову
- `tsim/` — движок: `geom.py`, `compiler.py`, `generators.py`, `scenery.py`, `signals.py`, `sim.py`, `env.py`, `run.py`, `worlds.py`, `server.py`
- `web/` — страница (Vite + TypeScript + Three.js), собирается в `web/dist` (в git не входит)
- `tests/` — компилятор, ядро, светофор, среда и сервер
