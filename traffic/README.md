# Транспортная симуляция

Второй проект в репозитории, с Loom не связан. Симулятор городской транспортной сети (улицы, перекрёстки, машины, светофоры, пешеходы, ДТП), на котором нейросеть учится управлять светофорами.

Статус: проект. Кода симуляции, компилятора и отрисовки ещё нет.

## Файлы

- `docs/design.md` — принятые решения, устройство, порядок работы
- `docs/world-format.md` — формат описания мира и правила компилятора
- `schema/world.schema.json` — схема описания мира (JSON Schema 2020-12)
- `examples/cross.json` — пример: перекрёсток магистрали и улицы, карман для левого поворота, переход посреди квартала

Проверка примера по схеме:

```
python3 -c "import json,jsonschema; jsonschema.validate(json.load(open('examples/cross.json')), json.load(open('schema/world.schema.json')))"
```
