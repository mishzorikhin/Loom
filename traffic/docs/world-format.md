# Формат описания мира

Контракт между человеком (или генератором) и компилятором сети. Схема — `schema/world.schema.json` (JSON Schema 2020-12), пример — `examples/cross.json`. Здесь правила, которые схема выразить не может, и что из описания выводит компилятор.

Статус: формат версии 1, компилятор — `tsim/compiler.py`, проверки — `tests/test_compiler.py`.

## Соглашения

- Формат — JSON. YAML допустим как запись того же самого и переводится в JSON без потерь, канонический файл — JSON.
- Единицы: метры, секунды, скорости в м/с. Координаты: `x` на восток, `y` на север.
- Движение правостороннее.
- Идентификаторы — `^[a-z][a-z0-9_]{0,31}$`, стабильные. На них ссылаются правки экспериментов, журнал, кадры и нейросеть, поэтому имя не меняют без нужды.
- Описание содержит смысл (полосы, стрелки, переходы, фазы). Геометрию разметки, коннекторов и асфальта не пишут руками: её выводит компилятор.

## Узлы

`nodes.<id>` — `pos` и `kind`:

- `signal` — перекрёсток со светофором. Для него обязателен `junctions.<id>.signal`.
- `boundary` — край сети. Здесь появляются и исчезают машины и пешеходы. Ровно одна дорога.

Нерегулируемые перекрёстки (`priority`) — замысел, в версии 1 их нет.

## Дороги и полосы

`roads.<id>` соединяет `from` и `to`. Осевая линия — `from`, точки `shape`, `to`.

- `forward` — полосы в направлении `from → to`, `backward` — обратно. Порядок в обоих списках от бордюра к центру: индекс 0 — крайняя правая полоса.
- `turns` — стрелки полосы, то есть разрешённые движения в узле, **куда полоса ведёт**: `left`, `straight`, `right`, `uturn`. Примеры: `["straight", "right"]` — прямо и направо, `["left"]` — только налево.
- У полосы, ведущей в узел `boundary`, стрелок нет. У полосы, ведущей в узел `signal`, стрелки обязательны.
- `length` — карман: полоса существует только на последних `length` метрах перед стоп-линией. Компилятор строит отгон (сужение) перед карманом.
- `median.width` — разделительная полоса между направлениями.
- `sidewalk.left/right` — тротуары по направлению `from → to`; `0` — тротуара нет.
- `solid_before_stop` — сплошная между попутными полосами перед стоп-линией. Перестраиваться можно только через прерывистую.

## Перекрёстки

`junctions.<id>`, где `<id>` — узел `signal`.

### Переходы

- `auto` — переход на каждом луче, у которого есть тротуар с обеих сторон.
- `none` — переходов нет.
- Список `{arm, width, offset}` — только указанные.

Переход называется по лучу, через который идёт: в сигнальных группах пишут имя дороги (`"crosswalks": ["re", "rw"]`). Внутренний id перехода — `<узел>.cw.<дорога>`.

### Коннекторы

Коннектор — путь машины через перекрёсток от конца полосы подхода к началу полосы выезда.

При `auto` компилятор выводит коннекторы из стрелок:

1. Для каждого движения подхода определяется дорога выезда по углу между лучами: самый правый луч — `right`, ближайший к продолжению — `straight`, самый левый — `left`; `uturn` — тот же луч.
2. Полосы подхода со стрелкой этого движения сопоставляются полосам выезда по порядку. Правые повороты — в правые полосы, левые — в левые, прямые — один к одному, если число полос совпадает.
3. Если полос подхода больше, чем полос выезда, лишние присоединяются к ближайшей полосе выезда (слияние). Если меньше, крайние полосы выезда остаются без коннектора.

Список `connections` задаёт соединения явно и заменяет автоматические для упомянутых полос подхода. Явный коннектор должен соответствовать стрелке полосы, иначе это ошибка.

### Светофор

`signal: "auto"` (так делают генераторы) — фазы выводит компилятор:

- пара встречных лучей, у которых поворот налево только из отдельных полос, получает две фазы: прямо и направо вместе с пешеходами на лучах выезда направо (`<пара>_main`, `ped_<пара>`), затем налево (`<пара>_left`);
- остальные лучи — по фазе на луч со всеми его движениями, плюс пешеходы на луче, куда с него поворачивают направо;
- переходы, не попавшие ни в одну фазу, — отдельной пешеходной фазой;
- пределы по умолчанию: зелёный 5–90, жёлтый 0–6, весь красный 0–4, мигающий 0–20 с.

Имена групп и фаз — по сторонам света лучей (`n`, `ne`, …, `p_ns`, `p_ns_left`, `p_e`).

Явный светофор:

- `groups` — сигнальные группы. Группа машин — список движений `"<дорога-подход>:<движение>"`. Группа пешеходов — список переходов. Смешивать машины и пешеходов в одной группе нельзя.
- `phases` — фазы, каждая — набор зелёных групп. Порядок фаз не обязателен для контроллера: он может выбрать любую.
- `bounds` — пределы длительности стадий: `green`, `yellow`, `all_red`, `ped_flash` (мигающий зелёный пешеходам). Внутри пределов длительность выбирает контроллер, в том числе опасно малую (решение «вариант B», см. `design.md`). Нижние пределы могут быть нулевыми.

Порядок стадий держит код: зелёный → жёлтый (машинам) и мигающий (пешеходам) → весь красный → следующий зелёный.

## Переходы посреди квартала

`midblock_crosswalks[]` — переход на дороге в точке `at` (метры от узла `from`). В версии 1 только `signal: button`: светофор по вызову, узел `mb_<id>` с группами `veh` и `ped` и фазами «машинам» и «пешеходам». Во всех режимах управления он работает по вызову: пешеходам — после 20 с зелёного машинам, если кто-то ждёт, затем обратно через 8 с. Стоп-линии стоят на всех полосах дороги за 1,5 м до перехода.

## Геометрия перекрёстка

- Ядро луча — наибольшая полуширина проезжей части других лучей, делённая на синус угла между лучами (не меньше 0,45; почти встречные лучи не учитываются), плюс радиус бордюра 4 м.
- Переход: от ядра отступ `offset`, ширина `width`; стоп-линия на 1 м дальше перехода. Без перехода стоп-линия на 0,5 м за ядром.
- Асфальт перекрёстка — многоугольник по стоп-линиям лучей и скруглённым углам бордюра между соседними лучами.
- Тротуары встречаются на углах кривыми; переход — прямое ребро графа тротуаров между ними.

## Проверки компилятора

Ошибки, которые не выражает схема. Каждая сообщается с путём к месту в описании.

- Ссылки: `from`, `to`, `arm`, движения групп и группы фаз ссылаются на существующие объекты.
- `boundary` — ровно одна дорога; `signal` — не меньше трёх лучей и есть `junctions.<id>.signal`.
- У полосы к `signal` есть стрелки, к `boundary` — нет.
- Каждая стрелка имеет коннектор: у движения есть дорога выезда и на ней есть полоса.
- Каждое движение подхода входит хотя бы в одну сигнальную группу, каждый переход — хотя бы в одну пешеходную группу.
- `length` кармана меньше длины дороги, `at` перехода внутри дороги и вне зоны перекрёстка.
- Пределы `bounds`: нижний не больше верхнего.
- Движение и переход входят ровно в одну группу.
- **Безопасность фаз**: в одной фазе зелёные коннекторы машин не могут пересекаться. Слияние в одну полосу допустимо: машины пропускают того, кто ближе к точке слияния. Конфликт машины с пешеходом в одной фазе допустим: он получает правило `yield`, машина уступает. Иначе фаза отвергается.

## Что выводит компилятор

Скомпилированная сеть — единственный источник и для симуляции, и для отрисовки. Руками не правится.

```
Link        полоса или коннектор: id, kind (lane | conn), poly (ломаная + s), speed, width,
            turns, pocket, next / prev, left / right (соседние попутные полосы),
            change_zone (где можно перестроиться, по расстоянию до конца), conflicts, stops,
            для коннектора: junction, movement, group, from_lane, to_lane
Crosswalk   id, junction, road, axis (ломаная + s), width, group, edge (ребро тротуаров), conflicts
SwNode/SwEdge  граф тротуаров: walk (вдоль дороги), corner (угол), cross (переход)
Conflict    other (link | cw), other_idx, s_self, s_other, kind (cross | merge | ped), rule (protected | yield)
Stop        стоп-линия перехода посреди квартала на полосе: s, junction, group
Junction    id, kind (signal | midblock), pos, groups, phases, bounds, safe, polygon, approaches, crosswalks
render      примитивы для страницы: roads, junctions, sidewalks, medians, lines (solid | dashed),
            arrows, stops, zebras, hatches, heads (светофоры), bbox
hash        хеш описания
```

Id выводятся из описания и стабильны: полоса — `<дорога>.<side>.<index>`, коннектор — `<узел>:<полоса подхода>><полоса выезда>`, переход — `<узел>.cw.<дорога>` или `mb_<id>.cw`. Для страницы сеть уходит как `net_json` (пути по номерам, конфликты, группы, примитивы).

## Изменения формата

Поле `version` растёт при несовместимом изменении. Компилятор принимает только известные версии и не угадывает.
